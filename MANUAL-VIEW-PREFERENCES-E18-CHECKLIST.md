# Lista de pruebas manuales — E18

## Instalación
- [ ] Confirmar que E17 ya está instalada.
- [ ] Reemplazar `index.html` y agregar el nuevo JS/CSS respetando rutas.
- [ ] Confirmar que no se requiere migración SQL.

## Preferencias
- [ ] Abrir **Más herramientas → Personalizar vista**.
- [ ] Elegir **Adaptable**, guardar y comprobar que en celular el detalle inicia plegado y en escritorio abierto.
- [ ] Elegir **Compacta** y verificar que el resumen diario y los detalles de comidas comiencen cerrados.
- [ ] Elegir **Completa** y verificar que los detalles comiencen abiertos.
- [ ] Añadir una comida nueva y comprobar que el modo elegido se aplique a la nueva tarjeta sin cerrar manualmente otra tarjeta abierta/cerrada.
- [ ] Cancelar el diálogo y comprobar que las opciones no guardadas no se apliquen.
- [ ] Usar Restablecer y Guardar para volver al modo Adaptable.
- [ ] Cerrar con Escape y comprobar que el foco vuelva a «Personalizar vista».
- [ ] Navegar el diálogo con Tab y Shift+Tab; el foco no debe escapar del diálogo.
- [ ] Comprobar en 320 px que el botón Guardar quede visible y que el contenido de opciones pueda desplazarse si hace falta.

## Última herramienta usada
- [ ] Activar **Recordar la última herramienta usada** y guardar.
- [ ] Abrir una herramienta, volver y abrir «Más herramientas»; confirmar que aparece el atajo a esa herramienta.
- [ ] Tocar el atajo y comprobar que ejecuta el botón original, sin duplicar lógica ni hacer doble escritura.
- [ ] Desactivar la preferencia y comprobar que el atajo desaparezca.

## Separación de cuentas y diseño
- [ ] Con dos cuentas de prueba en el mismo navegador, guardar una preferencia distinta para cada una y cambiar de cuenta.
- [ ] Confirmar que el modo y el atajo no se mezclen entre cuentas.
- [ ] Revisar 320 px, 390 px, tableta y escritorio, en ambos temas.
- [ ] Verificar que calorías, ingredientes, notas, consumo y acciones Editar/Eliminar mantengan su comportamiento anterior.
