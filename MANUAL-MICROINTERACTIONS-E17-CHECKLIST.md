# Lista manual — E17

Probar primero con una cuenta de prueba y sin datos importantes.

- [ ] Guardar una comida nueva: la tarjeta guardada recibe una señal visual breve, sin toast redundante.
- [ ] Editar una comida y guardar sus ingredientes: el área de detalles recibe feedback visual una vez confirmado el evento.
- [ ] Agregar alimento al borrador: el campo de resumen se destaca brevemente y el texto no se altera por E17.
- [ ] Guardar objetivos: el acceso a objetivos recibe una confirmación visual discreta.
- [ ] Verificar estado de sincronización guardado: la señal aparece solo para la cuenta activa.
- [ ] Expandir y contraer los detalles de una comida con mouse, dedo y teclado.
- [ ] Usar Tab/Enter para eliminar una comida y confirmar: el foco se mueve a la siguiente acción útil o a «Agregar comida» si ya no quedan tarjetas.
- [ ] Cancelar una eliminación: el foco no debe saltar a otra acción ni mostrar una confirmación de eliminación.
- [ ] Cambiar de cuenta y emitir/recibir una actualización: la tarjeta de la cuenta anterior no debe resaltarse.
- [ ] Activar «Reducir movimiento» en el sistema: no deben ejecutarse animaciones de desplazamiento, pulso o escala.
- [ ] Verificar el tema claro y oscuro y una pantalla estrecha de teléfono.
- [ ] Comprobar que los botones Editar, Eliminar, Agregar comida y las herramientas siguen funcionando como antes.

No hace falta ejecutar SQL para E17.
