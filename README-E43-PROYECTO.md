# AgendaFICH E43

E43 agrega exportación y copia del informe de impacto estimado en compras después de aplicar una plantilla semanal. La operación es de solo lectura: el reporte no modifica la lista oficial ni la despensa.

Para instalar sobre E42, consultá `README-INSTALACION-E43.md`. Para detalles técnicos y resultados de las pruebas, consultá `README-ETAPA-E43.md` y `E43-VALIDACION.txt`.
